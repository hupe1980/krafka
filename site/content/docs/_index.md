Fourteen guides, grouped by when you need them. Every code sample compiles
against the current release; the protocol and configuration references are
checked against the crate in CI.

If you are starting from nothing, read [Getting Started](@/docs/getting-started.md)
and then the guide for whichever client you need. If you are debugging
something specific, the [Configuration](@/docs/configuration.md) and
[Error Handling](@/docs/errors.md) references are the fastest routes in.
